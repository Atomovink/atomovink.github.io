# atomovink.github.io

Source for the Atomovink website, served by GitHub Pages at https://atomovink.github.io.

Plain HTML and CSS, no build step. Colours and fonts come from [`atomovink-brand`](https://github.com/Atomovink/atomovink-brand) (`assets/css/tokens.css`).

## Preview locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Structure

```
index.html            home page
research/exp-001.html EXP-001 research plan
404.html              not-found page
assets/css/           brand tokens + site styles
assets/img/           logos and social preview image
```
